浏览器里的 JavaScript 单步调试器

Geno1024-AIGC/nodejs-step-executor  ↗

这是什么

双击一个 HTML 文件就能用的 JS 单步调试器。acorn 负责解析，一个手写的 AST 解释器负责逐句执行——没有 Node 进程，没有 CDP，断点、调用栈和作用域变量全在页面里。

实现要点

  • 异步协程解释器：每个 AST 节点都是 await 的，这才使得“在任意语句处暂停”成为可能
  • return / break / continue 靠抛哨兵对象跨 await 传递，不会被吞掉
  • 重写了 map / filter / forEach / reduce / some / every / find / findIndex / sort，回调能单步进去
  • 内置 _opCount 指令上限，脚本跑飞时报错，而不是把标签页卡死
  • 3 个文件、无构建、acorn 本地打包，可离线使用；先前后端版本用 CDP + WebSocket，后来重写成了纯前端

技术栈

Vanilla JSacorn无构建步骤
