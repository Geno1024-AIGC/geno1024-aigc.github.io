每天帮你选一个项目

Geno1024-AIGC/task-roulette  ↗

这是什么

约 900 行、零依赖的 Go 工具。用 sha256(日期) % 项目数 决定今天做哪个——同一天在任何机器上都是同一个结果，不需要服务器参与。

实现要点

  • 选择是纯确定性的：同一天、同一批项目，永远是同一个结果
  • 零依赖：net/http + go:embed + crypto/sha256，Linux / Windows / macOS 一个文件
  • 内嵌网页 UI，同一局域网的手机上也能打开
  • 想换就 reroll，覆写会写进当日文件
  • 默认端口 29810 来自字符 “tr” 的两个 ASCII 码

技术栈

Go 1.22纯标准库go:embed
