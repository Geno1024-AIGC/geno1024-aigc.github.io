Geno1024-AIGC/toolbox  ↗

这是什么

一个 JSON 清单对应一个工具，把旁边这十几个仓库变成一个统一的启停面板。同一个核心库同时驱动 Qt 桌面 GUI 和 toolboxd 无头服务。

实现要点

  • 注册一个新工具只需要往 manifests/ 里丢一个 JSON 文件，不用改代码
  • 在 QTcpServer 上手写了约 150 行的 HTTP/1.1 服务器：请求解析、MIME 映射、静态资源与 Markdown 文档
  • 五种工具类型：service / webapp / desktop / android / document
  • 进程五态（Stopped / Starting / Running / Detached / Failed）、实时 PID、滚动日志、异步 TCP 健康探测
  • 自带一份 AGENTS.md，把提交信息规范写成 AI 代理也能照做的约定
