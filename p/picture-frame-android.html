给照片加相框

Geno1024-AIGC/picture-frame-android  ↗

这是什么

7 种相框样式、可调背景、渐变、比例和留白，导出 JPEG / PNG 进相册。预览和导出走的是同一套渲染代码。

实现要点

  • “预览不是导出的近似——它就是导出，只是画得小一点”
  • 自己实现的可分离盒式模糊和叠加矩形阴影，保证输出不随 Android 版本漂移
  • README 里写下了 canary 更新的威胁模型：清单被投毒也只能让更新失败，装不上别人的包——因为 Android 拒绝不同签名的更新
  • CI 真的跑 testDebugUnitTest 和 lintDebug 并当门禁用，不是只 assemble 一下
  • 7 个一键预设：拍立得、暗夜、虚化、暖阳、双线、留白、白边
