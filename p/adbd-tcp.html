adbd-tcp

基本可用

让手机开启无线 ADB，从此不用插数据线

Geno1024-AIGC/adbd-tcp  ↗

这是什么

一个极小的 Android 应用：用 root 设置 service.adb.tcp.port，再用 setprop ctl.start / ctl.stop 控制 adbd 服务，把手机变成可以无线连接的 ADB 设备。

实现要点

  • 零依赖：不用 AndroidX、不用任何 UI 框架，一个 Activity 加一个布局就完了
  • 146 行的 MainActivity，所有 su -c 调用都放在后台线程上
  • 实时读回 service.adb.tcp.port 与 init.svc.adbd 的状态，端口号持久化到 SharedPreferences
  • GitHub Actions 每次 push 构建一个 892 KB 的 debug APK 并传成 artifact
