把纯文本流程编译成单文件交互指南的小型 DSL

Geno1024-AIGC/step-language  ↗

这是什么

用纯文本描述分步流程：步骤、勾选项、提问分支、提示、警告、图片和代码块各占一行，编译器产出一个可离线、可打印、带进度保存的独立 HTML 页面，图片保持外链懒加载。编译器只用 Python 标准库，生成的页面只用原生 CSS 和 JavaScript。

实现要点

  • 生成的 body 是空壳：每个字都由内嵌的 JSON 在客户端渲染。8 步示例 54 KB，其中 46 KB 是 CSS 和 JS 骨架，真正的内容只有 4.9 KB
  • 编译器 1,656 行，全是 Python 标准库，零依赖；生成的页面没有外部 link、没有外部 script，字体走系统栈
  • 跳转目标先收集、最后统一解析，所以前向引用不用预读、也不用二次读文件；再从 @start 做一次可达性 DFS，够不着的步骤会直接报出警告
  • 勾选进度存在 localStorage，键里带 @version——改版本号不只是忽略旧进度，启动时会把旧键整个删掉
  • 浏览器里那份编译器是手写的 JS 移植版；CI 用 Node 调起 Python 解析器，把两边的解析结果和警告逐字段比对，不一致就让构建失败

技术栈

Python 3.10+纯标准库Vanilla JS无构建步骤
