把任意文件夹变成定时 Git 备份

Geno1024-AIGC/scheduled-backup  ↗

这是什么

常驻系统托盘的 Qt 小工具，按间隔执行 git add → commit → push 到一个私有的 GitHub 或 Gitee 仓库。首次配置由向导弹导完成。

实现要点

  • 向导弹导：选平台 → 一键注册 → 建 PAT → 自动创建私有仓库 → 生成 .gitignore → 首次推送
  • 直接 shell out 到系统的 git，token 留在本地凭据文件里，永远不会进备份内容
  • 历史页签：待提交变更、commit 日志、每个 commit 的文件列表
  • 提交信息按改动大小分级：{Init} / [Update] / (Fix)
  • README 认真写了没有 root 权限的 Linux 上打包 Qt 6 的真实路径，以及静态 Qt 和 AppImage 单文件两条路
