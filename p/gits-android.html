手机上的完整 Git 客户端

Geno1024-AIGC/gits-android  ↗

这是什么

基于 Eclipse JGit 的 Android Git 客户端。克隆、拉取、暂存、提交、储藏、blame 和 diff 全部在设备上完成，外加一层自己实现的 OpenPGP，用来给提交签名。

实现要点

  • 三个模块：app（Compose 界面）、git-core（683 行核心 API）、openpgp
  • 自建 OpenPGP 层：密钥生成、钥匙串、ASCII armor、分离式签名，不捆绑任何 gpg 二进制
  • 216 个单元测试直接拿真 gpg 和真 git 校验：签名、验签、verify-commit 都对着真二进制跑，机器上没装就自动跳过
  • CI 用 apksigner 读出签名证书的 SHA-256，对不上就拒绝出包；换成组织共用证书后，旧证书签的版本再也盖不上去
  • 每次绿灯都重建同一个 pre-release 标签，App 轮询 api.github.com 拿版本，自己下载并调 PackageInstaller 装上

技术栈

Kotlin 2.4Jetpack ComposeEclipse JGitBouncyCastleGradle
