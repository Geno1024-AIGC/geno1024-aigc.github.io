Windows 上的 mhwd

Geno1024-AIGC/whwd  ↗

这是什么

纯 C11 Win32 写的硬件检测与驱动更新工具，命令行和参数刻意对齐 Manjaro 的 mhwd。不依赖 .NET。

实现要点

  • 用 SetupAPI 枚举设备，输出 HWID、名称、驱动版本、日期、提供商和实例 ID
  • 通过 ntdll!RtlGetVersion 探测系统特性，绕过被应用清单撒谎的 OS 版本
  • 通过 Windows Update 的 IUpdateSearcher 列出驱动，源适配器藏在统一的 C 接口后面
  • x86 上用 v141_xp 工具集仍能编译出支持 Windows XP SP3 的版本，Win7 SP1 及以上则是另一套目标
  • JSON 是 CLI 和 GUI 之间的契约：命令行和 Win32 ListView 界面跑的是同一套核心代码
