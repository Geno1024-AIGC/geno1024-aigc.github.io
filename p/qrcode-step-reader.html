qrcode-step-reader

把二维码的解码过程动画化

Geno1024-AIGC/qrcode-step-reader  ↗

这是什么

读到二维码之后，它把整个解码过程分阶段回放：取样 → 二值化 → 校正 → 格式信息 → 去掩码 → 读位 → 分块 → Reed–Solomon 校验 → 文本。每一步下面写的都是真实的中间值，不是泛泛的说明。

实现要点

  • 解码器从零手写：定位图形交叉校验、透视校正、格式信息 BCH 解码、8 种数据掩码、GF(256) 上带真实伴随式计算的 Reed–Solomon
  • 解码器返回的是一条时间线而不是一个字符串：每一阶段都带完整的模块矩阵和单元格角色标注
  • 掩码公式直接写进双语字幕，例如 ((y·x) % 3 + (x + y) % 2) % 2 == 0
  • 拿 ZXing 生成的测试图做交叉验证（ZXing 只出现在测试依赖里，解码器本身不依赖它）
  • 一套 Compose Multiplatform 代码同时服务 Android 相机与桌面文件选择器，打包成 Deb / Rpm / AppImage

技术栈

Kotlin MultiplatformCompose MultiplatformCameraXZXing (仅测试)
