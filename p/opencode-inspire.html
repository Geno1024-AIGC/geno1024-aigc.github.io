opencode-inspire

手机上的 OpenCode 智能体客户端

Geno1024-AIGC/opencode-inspire  ↗

这是什么

连上跑着 opencode serve 的主机，挑一个项目目录，然后像聊天一样和编码智能体对话。自己写的 Markdown 渲染模块，内置 Mermaid 画图。

实现要点

  • 约 19,600 行 Kotlin、509 次提交，是这一组里迭代最久的项目
  • 手写的 Markdown 解析模块 + 打包进 assets 的 mermaid，回复里的图表直接渲染
  • 用量日历、按模型筛选的统计图表，以及可分享的总结卡片
  • 唯一有正式 release 工作流的仓库：打 tag 出已签名 APK
  • AGENTS.md 要求每次提交重新生成 tokens.txt，把造这个 App 实际花掉的 AI token 成本编译进 BuildConfig
