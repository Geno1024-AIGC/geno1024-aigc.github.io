手机上的 OpenCode 智能体客户端

Geno1024-AIGC/opencode-inspire  ↗

这是什么

连上跑着 opencode serve 的主机，挑一个项目目录，然后像聊天一样和编码智能体对话。自己写的 Markdown 渲染模块，内置 Mermaid 画图。

实现要点

  • 约 19,600 行 Kotlin、528 次提交，是这一组里迭代最久的项目
  • 手写的 Markdown 解析模块 + 打包进 assets 的 mermaid，回复里的图表直接渲染
  • token 用量按服务器切分：每台服务器有自己的 sid 和指纹；合并两台服务器是一次真正的数据迁移——去重合并统计、改写引用、重指活跃会话
  • 用量爬虫改成可续跑：每个会话一个同步游标，中途定期落快照，中断后从断点接着爬，而不是从头再来
  • OkHttp 的 keep-alive 竞态自己兜：EOF / unexpected end of stream 归为瞬时错误，只对幂等请求重试，重试前先清空连接池

技术栈

KotlinJetpack ComposeOkHttp 5kotlinx.serializationCoroutines
