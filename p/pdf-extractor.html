Geno1024-AIGC/pdf-extractor  ↗

这是什么

C++ / Qt5 写的 PDF 解析工具。刻意不做渲染器——它是一个检查器：把每个对象摊开给你看。

实现要点

  • 每个对象都有六个页签：结构树、解码文本、十六进制、图像、原始内容算子、字体
  • 手写的 CFF / Type1C / CIDFontType0C 字体解析器，能反汇编每个字形的 Type 2 charstring 程序
  • 解 FlateDecode（含 Predictor）、ASCII85、ASCIIHex、RunLength、LZW；图像流按原字节透传
  • 7 个 CLI 子命令，加中英双语界面、拖放打开、最近文件
  • Windows 打包会递归遍历 PE 导入表补齐 zlib / ICU / freetype，然后在没有 MinGW 的 cmd 里跑一遍，证明确实自包含
