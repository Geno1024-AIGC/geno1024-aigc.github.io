proxied-crawler

抓取网页响应体的中间人代理

Geno1024-AIGC/proxied-crawler  ↗

这是什么

把系统代理指向它，HTTP 响应体会按 URL 结构落盘。HTTPS 通过自签根 CA 加按域名现场签发的叶证书来解密。

实现要点

  • 纯 Go 标准库，go.mod 里一行 require 都没有
  • 首次运行自动生成根 CA，按域名现场签发叶证书
  • chunked 与 Content-Length 两种响应都处理，回写客户端时统一改写成定长
  • 内嵌 GUI：实时请求 / 字节 / 错误统计、可折叠的结果树、文件预览
  • 诚实的边界写在 README 里：整包响应缓存在内存里，只监听回环地址

技术栈

Go 1.22纯标准库crypto/x509embed
