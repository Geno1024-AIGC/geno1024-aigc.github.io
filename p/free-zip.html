把 ZIP 的“压缩”和“打包”拆成两件事

Geno1024-AIGC/free-zip  ↗

这是什么

自己实现的 ZIP 编解码器，Java 和 Kotlin 各写了一份，类级别一一对应。pack 把每个条目压缩成 .lfh / .data / .cdfh 三件套，assemble 退化成纯字节拷贝——同一份压缩数据可以反复组装成不同的归档。

实现要点

  • 直接对着 APPNOTE.TXT 写，每段代码都标注了对应的规范小节
  • size 子命令不读任何负载就能算出成品的精确 Content-Length
  • edit 只改元数据、绝不碰 .data，CRC 和长度天然保持有效
  • Zip64 支持 auto / always / never；选 never 时宁可硬失败，也不产出打不开的包
  • Java 和 Kotlin 两边互相组装验证；52 个 JUnit 测试在 CI 里跑，含 Zip64 溢出、超长文件名、重复条目等加固用例
